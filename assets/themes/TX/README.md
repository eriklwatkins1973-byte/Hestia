# Texas (TX) Branding Assets

Place the following files in this directory:

| File | Description |
|------|-------------|
| `logo.png` | State/tenant logo (PNG, 200×60 px recommended) |
| `splash.png` | Splash screen image (1080×1920 px) |
| `icon.png` | App icon override (1024×1024 px) |

## Color Palette

| Role | Hex |
|------|-----|
| Primary | `#BF5700` (Burnt Orange) |
| Accent | `#333F48` (Charcoal) |
| Background | `#FFFFFF` |
| Surface | `#F5F5F5` |
